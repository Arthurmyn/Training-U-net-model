Dice по каждому изображению при пороге 0.5, маски 256x256. 6 запусков: Kvasir-SEG и CVC-ClinicDB, сиды 1-3. Обучение на NVIDIA RTX 3050 (CUDA), 105 минут. Подробные таблицы: `results/summary.md`, `results/tables/`, график `results/fig_dice_distributions.png`.

## 5. Как читать результаты

- **Kvasir -> CVC:** падение около 0.17, весь интервал выше порогов 0.05 и 0.03. Порог 0.10 интервал пересекает, поэтому для него вывод неопределённый.
- **CVC -> Kvasir не интерпретируется как падение генерализации.** Модель, обученная на CVC, слабая даже на своём датасете (test Dice 0.38, интервал очень широкий). Причины, видимые в данных: мало обучающих кадров (429), много почти одинаковых кадров внутри последовательностей, в test всего 5 независимых последовательностей, запуски останавливаются рано. Для этого направления нужна доработка обучения; сейчас сравнивать его с обратным направлением нельзя.
- **Причина падения не установлена.** Эксперимент измеряет суммарный эффект (яркость, разрешение, эндоскоп, стиль разметки, число снимков, пациенты), а не вклад отдельного фактора.
- Разбиение CVC сделано по видеопоследовательностям, а не по пациентам; перекрытие пациентов между train и test исключить нельзя (`outputs/audit_report.md`). В `metadata.csv` 29 последовательностей, в описании базы 31.
- Пороги практической значимости (0.05, 0.03, 0.10), набор аугментаций и гиперпараметры выбраны при настройке пайплайна, не по результатам; сверьте их с методологией.
- Не проверено: примеры предсказаний (`runs/*/examples_*.png`) и кривые обучения моделей CVC.

## 6. Что лежит в репозитории

- `runs/<датасет>_seed<N>/`: `run.json`, `metrics.csv`, `per_image_dice.csv`, `eval_summary.json`, `examples_*.png`, **`best.pt`** (лучшие веса, 31 МБ).
- `last.pt` (последняя эпоха, 93 МБ) в репозиторий не включены: они нужны только для продолжения прерванного обучения.
- `results/`: итоговые таблицы и график (`python -m train.analyze` пересоздаёт их из `runs/`).
- `runs/run_all.log`: лог обучения.
- Датасеты не в репозитории (`data/`); как их получить и проверить: `docs/SETUP_ru.md`, `python -m train.verify_data`.

## 7. Как подтянуть на другом ноутбуке

```bash
git clone https://github.com/Arthurmyn/Training-U-net-model.git
cd Training-U-net-model
```
Установить зависимости и PyTorch (`docs/SETUP_ru.md`), положить данные в `data/`, затем `python -m train.analyze` для повторного анализа.
